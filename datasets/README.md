# Dataset

This project uses the PlantVillage dataset for crop disease classification.

## Final Dataset Used

- Total images: 31,397
- Classes: 25
- Crops: 5
- Training images: 25,108
- Validation images: 3,132
- Test images: 3,157
- Split: 80/10/10
- Random seed: 42

## Supported Crops

- Apple
- Corn
- Grape
- Potato
- Tomato

The complete image dataset is not included in this repository because of its size.

The dataset was used for academic machine learning experimentation and model development.
